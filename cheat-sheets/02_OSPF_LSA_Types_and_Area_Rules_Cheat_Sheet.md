# OSPF LSA Types & Area Architecture Cheat Sheet
### Cisco Certification Master Study Handbook — Quick Reference Series

---

## 📑 1. OSPF Link-State Advertisement (LSA) Hierarchy

| LSA Type | Name | Originating Router | Flooding Scope | Primary Purpose |
|:---:|:---|:---|:---|:---|
| **Type 1** | **Router LSA** | Every OSPF Router | Within originating area only | Lists router's active links, interfaces, IP addresses, and state. |
| **Type 2** | **Network LSA** | Designated Router (DR) | Within multi-access area only | Lists all routers attached to a broadcast multi-access Ethernet segment. |
| **Type 3** | **Summary LSA** | Area Border Router (ABR) | Regenerated into adjacent areas | Advertises inter-area network prefixes between OSPF areas. |
| **Type 4** | **ASBR Summary LSA**| Area Border Router (ABR) | Flooded to all areas except stub | Advertises the host route (/32) to reach an ASBR. |
| **Type 5** | **AS External LSA** | Autonomous System Boundary Router (ASBR) | Flooded throughout entire OSPF domain (except stub/NSSA) | Injects routes redistributed from external protocols (BGP, EIGRP, static). |
| **Type 7** | **NSSA External LSA**| ASBR inside a Not-So-Stubby Area (NSSA) | Within NSSA only | Injects external routes into an NSSA; translated to Type 5 by ABR at area boundary. |

## 🛡️ 2. Special OSPF Area Types Comparison Matrix

| Area Type | Type 1 & 2 | Type 3 (Inter-Area) | Type 4 (ASBR Summary) | Type 5 (External) | Type 7 (NSSA) | Default Route Injection |
|:---|:---:|:---:|:---:|:---:|:---:|:---|
| **Standard Area** | ✅ Yes | ✅ Yes | ✅ Yes | ✅ Yes | ❌ No | Manual via `default-information originate` |
| **Stub Area** | ✅ Yes | ✅ Yes | ❌ No | ❌ No | ❌ No | Automatic Type 3 default route generated by ABR |
| **Totally Stubby Area (TSA)** | ✅ Yes | ❌ No (except default) | ❌ No | ❌ No | ❌ No | Automatic Type 3 default route generated by ABR |
| **Not-So-Stubby Area (NSSA)** | ✅ Yes | ✅ Yes | ❌ No | ❌ No | ✅ Yes | Type 7 default injected via `area X nssa default-information-originate` |
| **Totally NSSA** | ✅ Yes | ❌ No (except default) | ❌ No | ❌ No | ✅ Yes | Automatic Type 3 default route generated by ABR |

## ⏱️ 3. OSPF Adjacency Requirements & Default Timers
For two OSPF routers to achieve **FULL** adjacency, these parameters MUST match exactly:
- [x] Area ID
- [x] Subnet mask on the link
- [x] Hello and Dead Intervals (Default: **10s / 40s** on broadcast/point-to-point; **30s / 120s** on Non-Broadcast Multi-Access NBMA)
- [x] Area flags (Stub / NSSA flags)
- [x] Authentication password and type
- [x] MTU size (mismatch causes adjacency to hang in **EXSTART / EXCHANGE** state)
